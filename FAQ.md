# FAQ

**Is this list complete?**  
No — AI products launch daily. We list major categories and official entry points.

**Open source vs open weights?**  
Many “open” models share **weights** but not training data. Read each **license** before commercial use.

**Best free coding AI for students?**  
Check [GitHub Copilot for students](https://education.github.com/), Continue + local model, or IDE trials — compare in README coding table.

**How is this different from [oss-programs-and-hackathons](https://github.com/Jay-Lokhande/oss-programs-and-hackathons)?**  
That repo lists **GSoC, internships, hackathons**. This repo lists **AI products and models**.
