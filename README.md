# All The AIs

A community catalog of **AI assistants, models, APIs, coding tools, and local LLMs** — what they’re for, who makes them, and official links.

> **Disclaimer:** Products rename and reprice constantly. Check official sites before signing up or sending data. Open a PR to fix outdated entries.

> **Safety:** Fake “ChatGPT” apps and API-key phishing are common → [resources/ai-scams.md](resources/ai-scams.md)
